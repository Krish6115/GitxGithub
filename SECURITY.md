# Security Policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Report them privately through [GitHub's private vulnerability reporting](https://github.com/Krish6115/GitKitty/security/advisories/new).

Include what you found, how to reproduce it, and the impact. You'll get a reply within a few days.

## Scope

- The Kitty Chrome extension (`kitty/extension`)
- The Kitty server (`kitty/server`) and the hosted instance at `kitty-server.vercel.app`

Of particular interest: leaked API keys, prompt injection that makes Kitty act against the user, and ways to abuse the hosted server.

## Supported versions

Only the [latest release](https://github.com/Krish6115/GitKitty/releases/latest) receives fixes.
