Kitty is a small, original pixel-art cat that lives on top of github.com pages as a Chrome extension and acts as a Git & GitHub companion. It gives developers a guided walkthrough of any repository (key files, stack, how to run and contribute) so they understand a codebase before handing it to an AI, tutors Git and GitHub concepts grounded in this repository's own learning materials plus openly licensed references (Pro Git, official Git and GitHub documentation), and explains selected commands, diffs and pull requests in plain language. All language understanding and generation is powered by BharatCode: the extension talks only to the Kitty server, which calls BharatCode's OpenAI-compatible Chat Completions API (model qwen-3.8-27b at https://bharatcode.ai/api/model/v1) with streamed responses, strict-JSON outputs validated on the server for repo tours, and lexically retrieved context chunks for tutoring, so API keys never ship inside the extension.
