# Code of Conduct

GitKitty is a place to learn, so everyone should feel welcome to ask questions, including beginner ones.

## Expected

- Be kind and patient, especially with newcomers.
- Give constructive feedback about the work, not the person.
- Respect different backgrounds, experience levels and opinions.

## Not acceptable

- Harassment, insults or discriminatory language
- Personal attacks or trolling
- Sharing someone's private information without permission

## Enforcement

Maintainers may remove comments, commits or issues that break these rules, and may block repeat offenders. Report problems to the maintainer, [Krish6115](https://github.com/Krish6115), through a private message or a [private security report](https://github.com/Krish6115/GitKitty/security/advisories/new).
